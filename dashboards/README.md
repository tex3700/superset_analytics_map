# Dashboards

В этой папке описываем дашборды Superset.

Для каждого дашборда фиксируем:

- назначение дашборда;
- аудиторию;
- список чартов;
- ключевые фильтры;
- основные датасеты;
- бизнес-логику интерпретации показателей.
