# Sources

В этой папке описываем первичные источники данных.

Источник отвечает на вопросы:

- откуда данные берутся изначально;
- какие сущности или отчеты забираются;
- какие есть ограничения API или исходной системы;
- какие поля важны для аналитики;
- какие процессы загружают эти данные в ADB.
