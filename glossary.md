# Glossary

## ADB

Основная база данных, из которой Superset берет данные для датасетов.

## Source

Первичный источник данных: внешняя API-система, внутренняя база данных, файл, сервис или ручной источник.

Примеры:

- Яндекс Директ
- Яндекс Метрика
- Яндекс Маркет
- Ozon
- Wildberries
- внутренняя операционная база

## Ingestion

Процесс загрузки данных в ADB.

Примеры:

- n8n workflow по расписанию
- PHP-скрипт через cron
- ручная загрузка
- SQL job

## Physical dataset

Датасет Superset, который напрямую смотрит на физическую таблицу или view в ADB.

## Virtual dataset

Датасет Superset, который построен на SQL-запросе. Для таких датасетов важно документировать полный SQL и все промежуточные агрегации.

## Grain

Уровень детализации строки в датасете.

Пример:

```text
1 строка = 1 день + 1 маркетплейс + 1 товар
```

## Metric

Числовой показатель, который используется в чарте.

Примеры:

- `SUM(revenue)`
- `COUNT(order_id)`
- `AVG(position)`

## Dimension

Поле, по которому данные группируются, фильтруются или раскладываются в чарте.

Примеры:

- дата
- маркетплейс
- товар
- рекламная кампания
